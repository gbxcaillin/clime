Shared storage on GitHub

The tracker keeps one JSON file in a GitHub repository. Everyone who connects reads and writes that file, each change becomes a commit, and the page checks for new commits on a timer, when you return to the tab, and after your own changes.

A fine-grained token with access to only this repository and the Contents permission set to Read and write. It is stored in this browser only. Anyone with the token can commit to the repository, so treat it like a password.
